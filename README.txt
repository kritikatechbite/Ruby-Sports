Ruby Sport - static website (HTML5, CSS3, vanilla JavaScript) for New Zealand

LIVE URL (GitHub Pages): https://kritikatechbite.github.io/RubySport/
Upload the CONTENTS of this folder into the RubySport repository (index.html must be at the repo root).
Review page: https://kritikatechbite.github.io/RubySport/review.html

NOTES
1. Canonical, Open Graph and sitemap URLs already use the domain above.
2. robots.txt only takes effect at a domain root. On a GitHub Pages project URL (/RubySport/) search engines
   ignore it. The sitemap can be submitted directly in Google Search Console.
3. Add a real contact email in about.html (#contact) and in the contact section of each policy page.
4. Images are generated illustrations (stand-ins). To use Unsplash photos, download them yourself and save over
   the files in assets/images/ (same file names, converted to .webp). Suggested Unsplash searches:
     hero.webp ............ "rugby stadium crowd", "new zealand sports"   (landscape, 16:10)
     rugby.webp ........... "rugby union match"                          (4:3)
     cricket.webp ......... "cricket match stumps"                       (4:3)
     netball.webp ......... "netball court"                              (4:3)
     football.webp ........ "football soccer pitch"                      (4:3)
     basketball.webp ...... "basketball court hoop"                      (4:3)
     sailing.webp ......... "sailing yacht harbour"                      (4:3)
     review-desktop.webp .. "stadium night lights"                       (16:9, 1920x1080)
     review-tablet.webp ... "stadium night lights" cropped               (4:5, 1200x1500)
     review-mobile.webp ... "stadium night lights" cropped               (9:16, 1080x1920)
   Check each photo's Unsplash licence/credit terms before publishing.
5. Event fixtures and articles are labelled demonstration/sample content. Replace with verified information
   before presenting them as real.
6. If you add analytics, cookies or third-party services, update the Privacy and Cookie policies.
